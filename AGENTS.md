# Website image accessibility and SEO

- Every meaningful HTML image must have descriptive alt text that accurately describes its visible content. Use relevant terms naturally; do not keyword-stuff or use filenames as alt text.
- Decorative images must use `alt=""`.
- When adding, replacing, or editing images, verify the alt text and image path. Review existing image alt text when working on a page.
- A meaningful image used as a CSS background must have equivalent descriptive information in nearby HTML.
- Do not add an image or alt description that misrepresents the image content.
